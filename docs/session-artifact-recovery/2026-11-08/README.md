## Scope and verification

This inspection covers the files areas of local sessions matching this exact worktree.
It does not include event databases, deleted saved edits, remote-only sessions, or attachments.
Every copied file is checked against its recorded hash. Original session bytes remain unchanged.
Existing artifact copies are not refreshed. Credential-like content, raw data, runtime packages,
unsupported formats, and disposable snapshots are excluded for separate review.
Images and PDFs require a separate visual/privacy retention review; they are not automatically imported.
The retained PNGs were reviewed as historical synthetic game screenshots; see the inspection contact sheet.
